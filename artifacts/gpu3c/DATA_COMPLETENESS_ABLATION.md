# 数据完整性修复审计

原始 512-context 处理共有 19,162 条实际训练样本，其中 12,469 条监督 assistant `<|im_end|>`，覆盖率 65.071%；6,693 条因 assistant 在结束标记前被截断而缺少 EOS 监督，另有 38 条 prompt 已耗尽 context、未进入实际训练。

D1 完整样本过滤保留 12,469/19,200 条，过滤 6,731 条，EOS 覆盖率为 100%；有效监督 token 从原方案 5,177,783 降为 2,583,463。来源和长度分布均明显变化，因此 D1 只作为数据处理综合方案，不把效果归因为 EOS。详细分布见 `data_audit.json`。

本轮 B/C 共同使用 D1 子集以隔离 EOS label；未另行启动 A/D 数据处理综合训练。
