## Known Limitations

- Native model is small and undertrained by modern standards.
- Native scores use fixed 64-example subsets; T2 remained 2/64.
- Qwen Full SFT effectiveness was not formally validated.
- PEFT conclusions are bounded to three seeds and context 512.
- Flash was unavailable and compile was blocked by missing Triton.
- No qualified accelerated-attention performance result exists.
- Distributed training, DPO, and GRPO were not executed.
- Hardware evidence comes from one RTX 5060 Laptop GPU Windows environment.

## Gate Decision

All blocking gates pass. The repository is suitable for public portfolio publication with
the documented limitations and historical path disclosures. Creating the annotated tag
and performing normal non-force pushes are authorized by this gate.
