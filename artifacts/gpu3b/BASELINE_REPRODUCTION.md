# GPU-3B 基线复现报告

## 结论

冻结权重下共重放 10 条历史基线生成，prompt token IDs 10/10 一致，输出 token IDs 10/10 逐 token 一致。后续配对比较具备严格复现基础。

## 冻结对象与环境

- 起点：GPU-3A `b41c718c337946c14a0bf80dcbacf68a1129d633`；协议：`gpu3b-v2-frozen`。
- 模型：`Qwen/Qwen3-0.6B-Base`，4 个 seed=42 代表性 PEFT adapter；没有训练或权重更新。
- 硬件：RTX 5060 Laptop GPU（8,151 MiB），新推理峰值显存 1306.6 MiB。
- 单条上限 120 秒、最多 768 个新 token、最多 96 条新生成；实际 34 条，无 OOM/超时。
- 历史输入哈希复核 24 个文件，全部匹配：`True`。
